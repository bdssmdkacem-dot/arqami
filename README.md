# أرقامي (Arqami)

تطبيق Flutter تعليمي للرياضيات باللغة العربية، للفئة العمرية **3–16 سنة**. يعتمد على منهج من **52 وحدة** مع دروس، أنشطة تفاعلية، Quiz، Assessment، نجوم، تقدم محلي، وخريطة رحلة تعليمية بأسلوب ألعاب المسارات.

> **الحالة الحالية — 17 سبتمبر 2026:** المنهج ومحرك الأنشطة والتقدم وخريطة الرحلة قيد البناء المتكامل. تمت إضافة مكافآت نهاية المراحل كعناصر قابلة للتحصيل، مع حفظها محلياً وربطها بالـAchievements.

## 🎯 الرؤية

المسار الأساسي لكل وحدة:

**تعلّم المفهوم → مثال → نشاط تفاعلي → تدريب Quiz → Assessment → نجوم وتقدم → فتح الوحدة التالية.**

الهدف هو تحويل الوحدات الـ52 إلى رحلة تعليمية واحدة، دون جعل التطبيق مجرد MCQ.

## 📚 المنهج — 52 وحدة

- **1–13:** الأعداد 0–10، العد، الكميات، التتبع، المقارنة والمراجعة.
- **14–20:** الآحاد والعشرات والأعداد حتى 100 والبناء والتفكيك والمقارنة والترتيب.
- **21–34:** المئات والآلاف والقيمة المكانية والمراجعات.
- **35–40:** الجمع والطرح والتطبيقات والمسائل اللفظية.
- **41–46:** الضرب والقسمة والباقي والعمليات الأربع.
- **47–50:** الكسور والأعداد العشرية والعمليات عليها.
- **51–52:** النسبة والتناسب والنسبة المئوية والتعبيرات والمعادلات والمتباينات.

مصدر البيانات الرئيسي:

```text
lib/models/units_data.dart
lib/models/unit_model.dart
```

## 🎮 محرك الأنشطة

المشغل الرئيسي:

```text
lib/screens/unit_player_screen.dart
```

يدعم المشروع Lesson وQuiz وReview وAssessment وArithmetic وWord Problem وTrace وMatching وComparison وScene Explore وDrag Count وغيرها حسب الوحدة.

تمت إضافة اختبارات سلوكية للتأكد من أن النشاط يحقق هدفه التعليمي فعلياً، بما في ذلك حالات الصفر في Drag Count والتساوي في Comparison وبعض حالات Matching الملتبسة.

## ⭐ التقدم

```text
lib/core/progress/progress_tracker.dart
lib/core/progress/unit_progress.dart
```

التقدم محلي باستخدام Hive، والقواعد الأساسية:

1. الوحدة الأولى مفتوحة دائماً.
2. لا تفتح الوحدة التالية قبل إكمال السابقة.
3. لا يمكن تخطي وحدة.
4. أفضل نتيجة بالنجوم محفوظة.
5. المحاولات مسجلة.
6. إكمال الوحدة لا يتم إلا بعد مسار أنشطتها والتقييم النهائي.
7. التقدم يحسب من أصل 52 وحدة.

### 🏆 مكافآت المراحل والـAchievements

تعريفات المكافآت موجودة في:

```text
lib/models/stage_reward.dart
```

وحالة التحصيل محفوظة في `ProgressTracker` بشكل مستقل عن UI والصوت:

```text
StageRewardStatus.locked
StageRewardStatus.available
StageRewardStatus.claimed
```

لكل مرحلة مكافأة واحدة. لا تصبح قابلة للتحصيل إلا بعد إكمال جميع وحدات المرحلة، ولا يمكن جمعها مرتين. عند الجمع يتم أيضاً فتح Achievement المرحلة وحفظه محلياً.

الخريطة تعرض المكافأة بعد آخر وحدة في كل مرحلة، مع حالات مرئية للقفل، الجاهزية والجمع. الضغط على مكافأة جاهزة يطلق حركة احتفال وصوت فتح، ثم تظهر المكافأة والنجوم وتبقى حالة الجمع بعد إعادة فتح التطبيق.

## 🗺️ خريطة الرحلة

```text
lib/screens/units_map_screen.dart
```

الخريطة الحالية تتضمن:

- مساراً متعرجاً للوحدات.
- عقداً للوحدات المكتملة والحالية والمغلقة.
- نجوماً مرتبطة بنتيجة الوحدة.
- شخصية Companion تتحرك مع التقدم وفتح الوحدة التالية.
- فواصل مراحل واضحة.
- **عقد مكافآت حقيقية في نهاية كل مرحلة.**
- مكافآت قابلة للتحصيل مرتبطة مباشرة بـ`ProgressTracker`.
- احتفال بصري وصوتي عند جمع المكافأة.
- عداد مكافآت المراحل في رأس الخريطة.
