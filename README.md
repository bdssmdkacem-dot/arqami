# أرقامي (Arqami)

تطبيق Flutter تعليمي للرياضيات باللغة العربية للفئة العمرية **3–16 سنة**. يعتمد على منهج من **52 وحدة** مع دروس، أنشطة تفاعلية، Quiz، Assessment، نجوم، XP، إنجازات، تقدم محلي، وخريطة رحلة تعليمية بأسلوب ألعاب المسارات.

> **الحالة الحالية — 17 سبتمبر 2026:** المنهج ومحرك الأنشطة والتقدم وخريطة الرحلة تعمل كأساس متكامل. تم تثبيت نظام التصميم، ملف المتعلم العمري، مكافآت المراحل، XP والإنجازات، وتطوير عالم الخريطة وشاشة اللعب، وإضافة طبقة تكييف حقيقية لنوع النشاط وحجم التدريب بحسب العمر. التحقق النهائي عبر Analyze/Test/APK/AAB يبقى بوابة إغلاق المرحلة.

## 🎯 الرؤية

المسار الأساسي لكل وحدة:

**تعلّم المفهوم → مثال → نشاط تفاعلي → تدريب Quiz → Assessment → نجوم وXP → فتح الوحدة التالية → مكافأة المرحلة.**

الهدف هو تحويل الوحدات الـ52 إلى رحلة تعليمية واحدة، دون جعل التطبيق مجرد MCQ.

## 📚 المنهج — 52 وحدة

- **1–13:** الأعداد 0–10، العد، الكميات، التتبع، المقارنة والمراجعة.
- **14–20:** الآحاد والعشرات والأعداد حتى 100 والبناء والتفكيك والمقارنة والترتيب.
- **21–34:** المئات والآلاف والقيمة المكانية والمراجعات.
- **35–40:** الجمع والطرح والتطبيقات والمسائل اللفظية.
- **41–46:** الضرب والقسمة والباقي والعمليات الأربع.
- **47–50:** الكسور والأعداد العشرية والعمليات عليها.
- **51–52:** النسبة والتناسب والنسبة المئوية والتعبيرات والمعادلات والمتباينات.

مصدر البيانات الرئيسي:

```text
lib/models/units_data.dart
lib/models/unit_model.dart
```

## 🎮 محرك الأنشطة وطريقة الإجابة

المشغل الرئيسي:

```text
lib/screens/unit_player_screen.dart
```

يدعم Lesson وQuiz وReview وAssessment وArithmetic وWord Problem وTrace وMatching وComparison وScene Explore وDrag Count وغيرها حسب الوحدة.

طبقة الإجابة الحسابية تتعامل مع الأرقام العربية والهندية الغربية والفواصل العشرية الشائعة وبعض صيغ الأعداد العربية المكتوبة بالكلمات. توجد اختبارات سلوكية لحالات الصفر في Drag Count والتساوي في Comparison وبعض حالات Matching الملتبسة.

## 👤 ملف المتعلم والفئة العمرية

يُحفظ عمر المتعلم محلياً لتخصيص التجربة دون إنشاء حساب:

```text
lib/core/profile/learner_profile.dart
lib/core/profile/age_activity_presentation.dart
lib/core/profile/age_activity_adapter.dart
```

الفئات:

- **3–5:** عدّ، سحب، مطابقة، تتبع، توجيه بصري وصوتي، وتدريب قصير.
- **6–9:** أنشطة ملموسة أولاً، ثم Quiz وحساب تدريجي، مع تدريب أوسع قليلاً.
- **10–12:** تركيز أكبر على الحساب والمسائل والمقارنة، مع توجيه أقل.
- **13–16:** ترتيب يقدّم الحساب والمسائل متعددة الخطوات، مع أقل قدر من التلميحات وبقاء التقييم كاملاً.

### التكييف الحقيقي للنشاط

طبقة `AgeActivityPlan` لا تغيّر منهج الـ52 وحدة ولا محتوى الـAssessment. بدلاً من ذلك، تعيد ترتيب **نوع النشاط** بحسب أسلوب التعلم للفئة العمرية، وتحدد حجم التدريب غير التقييمي:

| الفئة | أولوية اللعب | حجم التدريب | التوجيه |
|---|---|---|---|
| 3–5 | Lesson → Trace/Drag/Matching → Quiz → الحساب عند وجوده | حتى 2 سؤال تدريب | مرتفع |
| 6–9 | Lesson → الأنشطة الملموسة → Quiz → الحساب | حتى 3 أسئلة تدريب | مرتفع |
| 10–12 | Lesson → Arithmetic/Word Problem → Comparison/Quiz | كامل | منخفض |
| 13–16 | Lesson → Arithmetic/Word Problem → Quiz/Review | كامل | منخفض |

أما `Assessment` فيبقى كاملاً وفي نهاية الوحدة، حتى لا يؤدي التكييف إلى تغيير معيار إتقان المنهج.

## ⭐ التقدم وXP

```text
lib/core/progress/progress_tracker.dart
lib/core/progress/unit_progress.dart
lib/core/progress/player_xp.dart
```

التقدم محلي باستخدام Hive. الوحدة الأولى مفتوحة، ولا تفتح الوحدة التالية قبل إكمال السابقة. أفضل نتيجة بالنجوم محفوظة، والمحاولات مسجلة، وXP مشتق من إكمال الوحدات والنجوم ومكافآت المراحل والإنجازات.

## 🏆 مكافآت المراحل والإنجازات

التعريفات في:

```text
lib/models/stage_reward.dart
```

وحالة التحصيل محفوظة في `ProgressTracker` عبر:

```text
StageRewardStatus.locked
StageRewardStatus.available
StageRewardStatus.claimed
```

لكل مرحلة مكافأة واحدة. لا تصبح قابلة للتحصيل إلا بعد إكمال جميع وحدات المرحلة، ولا يمكن جمعها مرتين. عند الجمع يتم فتح Achievement المرحلة وحفظه محلياً.

lib/screens/units_map_screen.dart

الخريطة تتضمن مساراً متعرجاً، عقداً للحالات المكتملة والحالية والمغلقة، نجوماً، Companion، فواصل مراحل، عقد مكافآت، احتفالاً بصرياً وصوتياً، وحركة انتقالية عند فتح المستوى التالي.

خلفية العالم الإجرائية تتضمن مناطق لونية هادئة، تلالاً، أشجاراً، غيوماً، بركة، أزهاراً وتفاصيل أرضية، مرسومة بـCanvas بدلاً من الاعتماد على بلاطة خلفية صغيرة مكررة.

## 🎮 شاشة اللعب

المشغل الرئيسي هو:

```text
lib/screens/unit_player_screen.dart
```

تم صقل الشاشة لتصبح جزءاً من تجربة اللعبة بدلاً من كونها بطاقة أسئلة فقط، مع الحفاظ على محرك الأنشطة والبيانات والتقدم كما هي.

تمت إضافة:

- HUD واضح يبيّن العالم، رقم المستوى، مرحلة النشاط، ونطاق العمر.
- شريط تقدم متحرك داخل الوحدة.
- بطاقات لعب موحدة ذات حواف وظلال وهوية أرقامي.
- حالات مرئية للإجابة الصحيحة والخاطئة.
- تغذية راجعة قصيرة ومناسبة للعمر.
- أحجام نصوص وأزرار متكيفة مع الفئات العمرية الأربع.
- واجهة Lesson أكثر وضوحاً مع أمثلة وزر بدء واضح.
- واجهة Arithmetic مخصصة للإجابة وإظهار الإرشاد عند الحاجة.
- احتفال إكمال الوحدة مع نجوم ورسالة مرتبطة بالنتيجة.
- الحفاظ على AudioService وProgressTracker وAssessmentEngine وAdService دون تغيير قواعدها الأساسية.
