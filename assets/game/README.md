# أصول اللعبة — Arqami Game Assets

هذه الطبقة تجمع الأصول الفعلية المستخدمة في هوية لعبة أرقامي.

## الهوية الموحدة

- **العالم والخريطة:** Kenney Tiny Town — CC0
- **الشخصية المرافقة:** Kenney Roguelike Characters — CC0
- **واجهة الخريطة:** Kenney UI Pack — CC0
- **الأيقونات:** Kenney Game/Board Game Icons — CC0
- **الصوت:** Kenney UI Audio — CC0
- **المؤثرات الإضافية:** Tiddybub 2D Assets — CC0 عند استخدام ملف محدد

## بنية الأصول

```text
assets/game/
├── backgrounds/
├── characters/
├── effects/
├── numbers/
├── rewards/
├── sounds/
└── ui/
```

## الربط داخل اللعبة

- `backgrounds/` ← عالم الخريطة ومسار الرحلة.
- `characters/` ← الشخصية المرافقة.
- `ui/` ← لوحات وعقد وأزرار الخريطة.
- `rewards/` ← النجوم والمكافآت.
- `effects/` ← النجاح وفتح المستوى والاحتفال.
- `sounds/` ← النقر والفتح والنجاح.
- `numbers/` ← العناصر الرياضية الخاصة بالأنشطة.

الخريطة لا تملك حالة تقدم خاصة بها؛ حالة العقد تأتي من `ProgressTracker`.

## قاعدة الأعمار

نستخدم نفس الهوية الأساسية مع تغيير الحجم والحركة وكثافة المعلومات:

- 3–5: أرقام كبيرة، تفاعل بسيط، عدّ وDrag & Drop.
- 6–9: مستويات، نجوم، XP، جمع وطرح وقيمة مكانية.
- 10–12: واجهة أقل طفولية، ضرب وقسمة ومسائل متعددة الخطوات.
- 13–16: واجهة أكثر نضجًا وتمارين مركبة ومسائل تطبيقية.

## التراخيص

أصول Kenney المستخدمة في المشروع CC0 ويمكن استخدامها تجاريًا. نحتفظ بسجل المصدر والحزمة في `asset_manifest.json`، ولا نضمّن مكتبات كاملة لا نستخدمها فعليًا.

لا نربط الأصول مباشرة بـ`units_data.dart`; تبقى بيانات المنهج مستقلة، وتستخدم طبقة الخريطة/الثيم الأصول المناسبة حسب المرحلة.
