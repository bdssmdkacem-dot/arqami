# أصول اللعبة — Arqami Game Assets

هذا المجلد هو الطبقة الموحدة لأصول الواجهة والخريطة والأنشطة في أرقامي.

## المصادر المعتمدة

### Kenney — المصدر الأساسي
- Characters: Roguelike Characters
- World/map: Tiny Town
- UI: UI Pack
- Icons: Game/Board Game Icons حسب الحاجة
- Audio: UI Audio وغيرها من حزم الصوت المناسبة

صفحات Kenney الرسمية تؤكد أن أصول صفحات الـAssets مرخصة CC0 ويمكن استخدامها تجاريًا ولا تتطلب Attribution.

### Tiddybub — مصدر ثانوي للمؤثرات فقط
نستخدم منه مؤثرات 2D محددة عند الحاجة، وليس لخلط الهوية البصرية للتطبيق.

## بنية المجلد

```text
assets/game/
├── characters/   # الشخصيات الرئيسية والمساعدة
├── backgrounds/  # خلفيات وعناصر عالم الخريطة
├── ui/           # الأزرار واللوحات والعناصر المشتركة
├── numbers/      # أرقام وعناصر تعليمية خاصة بالرياضيات
├── rewards/      # النجوم، XP، الشارات، الجوائز
├── effects/      # النجاح، الظهور، الاحتفال، الحركة
└── sounds/       # أصوات الواجهة والنجاح والتفاعل
```

## قاعدة مهمة

لا ننسخ مكتبات الأصول كاملة إلى التطبيق. نختار فقط الملفات المستخدمة فعليًا، ونحتفظ بسجل المصدر والحزمة لكل أصل مضاف.

## مبدأ الأعمار

نستخدم نفس الهوية الأساسية مع تغيير كثافة العرض وحجم العناصر والحركة:

- 3–5: أرقام كبيرة، تفاعل بسيط، Drag & Drop وعدّ.
- 6–9: مستويات، نجوم، XP، جمع وطرح وقيمة مكانية.
- 10–12: واجهة أقل طفولية، ضرب وقسمة ومسائل متعددة الخطوات.
- 13–16: واجهة أكثر نضجًا، تمارين مركبة ومسائل تطبيقية.

## الخريطة

الخريطة المستقبلية ستكون رحلة واحدة متصلة للوحدات الـ52. لا نربط الأصول بالوحدات مباشرة داخل `units_data.dart`; تبقى بيانات المنهج مستقلة، وتستخدم طبقة الخريطة/الثيم الأصول المناسبة حسب المرحلة.
